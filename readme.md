# Sistema de Agendamentos para Barbearia

Sistema desenvolvido em Python para realizar agendamentos de clientes em uma barbearia pelo terminal.

## Sobre o projeto.

Este projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais da programação em Python, como:

- Funções
- Listas
- Dicionários
- Estruturas de repetição
- Estruturas condicionais
- Manipulação de arquivos JSON
- Modularização do código
- Validação de dados

Os agendamentos são armazenados em um arquivo JSON, simulando um pequeno banco de dados.

---

## Funcionalidades:

- Cadastro de novos agendamentos
- Escolha de serviço
- Escolha de dia
- Escolha de horário
- Validação do nome do cliente
- Impede horários já ocupados
- Cancelamento do agendamento
- Visualização de todos os agendamentos
- Armazenamento permanente em JSON

## Como executar?

Clone o repositório:

```bash
git clone https://github.com/PedroIRanz/AgendaBarbearia.git
```

Entre na pasta:

```bash
cd AgendaBarbearia
```

Execute:

```bash
python sistema_agendamento.py
```
